2. Vista de Despliegue Físico (Topología de Servidores)

Para la implantación del software, se estructura una infraestructura en la nube distribuida en 3 nodos físicos de hardware:

• Nodo Cliente (Hardware: PC/Smartphone): Aloja el artefacto de la Vista que consume la aplicación mediante HTTPS en el puerto 443.
• Nodo Servidor Cloud (Hardware: AWS EC2/Instancia virtual): Ejecuta el entorno del Controlador procesando peticiones a través de microservicios robustos.
• Nodo Servidor de Datos (Hardware: Database Server Dedicado): Almacena y protege el motor relacional que da soporte al Modelo de datos lógicos (Puerto 3306 TCP/IP).
